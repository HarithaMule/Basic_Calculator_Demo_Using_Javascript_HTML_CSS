This is a simple calculator built using JavaScript. It performs basic arithmetic operations 
such as addition, subtraction, multiplication, and division. 
The project is designed to demonstrate fundamental JavaScript concepts like functions, DOM manipulation, and event handling.

* Features
Accepts user input for numbers and operators.
Supports +, -, \*, and / operations.
Displays results dynamically in the calculator screen.
Includes Clear functionality to reset the input.
Error handling for invalid expressions (e.g., division by zero).

* Technologies Used
JavaScript (core logic)
HTML (structure for input and buttons)
CSS (basic styling, optional)
